# IRSocial
Plataforma digital que orienta os contribuintes sobre como realizar doações via Imposto de Renda de Pessoa Fisica de forma simples e segura, ao mesmo tempo em que oferece transparência sobre o destino e o impacto social dos recursos arrecadados, fortalecendo a confiança e o engajamento da sociedade.
